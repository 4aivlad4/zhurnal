# Инструкция для владельца проекта

Программировать не нужно. Ваша роль — запускать задачи, проверять результат на телефоне,
принимать решения и говорить с семьёй.

## Как устроена работа
- Весь путь разбит на этапы и небольшие задачи — `docs/plan.md`.
- **Одна задача — одна сессия** (один чат с Claude). Новая задача — новый чат:
  Claude не держит в голове лишнее, работает быстрее и дешевле.
- У каждой задачи есть карточка (`docs/tasks/…`): зачем, что будет сделано, как проверить.
- Решения записываются в `docs/decisions.md` — договорённости не теряются между сессиями.

## Как запустить задачу
1. Откройте Claude Code (claude.ai/code или приложение) на репозитории `4aivlad4/zhurnal`.
2. Напишите: **«Следующая задача»** (или «Задача 1.4»).
3. Получите короткий отчёт: что сделано, что проверить, есть ли вопросы.
4. На вопросы можно отвечать коротко: «а», «б», «как рекомендуешь».
5. Проверьте результат (ниже).

## Полезные фразы
| Фраза | Что будет |
|---|---|
| «Статус» | где мы, что следующее, что ждёт вашего решения |
| «Продолжи» | продолжить задачу с места, где остановились в прошлый раз |
| «Кончается контекст» | Claude сохранит рабочее состояние и опубликует его; дальше — новый чат и «Продолжи» |
| «Сломалось: …» | Claude найдёт и починит. Опишите: что делали → что ожидали → что увидели; можно скриншот |
| «Хочу изменить: …» | мелочь сделают сразу, крупное добавят в план |
| «Откати последнее» | сайт вернётся к предыдущей версии |
| «Объясни подробнее» | развёрнутый ответ по последнему отчёту |

Отчёты короткие специально — это экономия. Непонятно — просто спросите.

## Как проверить результат
- Откройте приложение на телефоне. Номер версии — в разделе «Ещё».
- Версия старая — закройте приложение полностью и откройте снова
  (или «Ещё → Обновить сейчас»).
- Пока семья не начала работать по-настоящему, проверяйте в **демо-режиме**:
  там выдуманные данные, ничего не сломаете.

## Принимать изменения не нужно
Claude сам сливает изменения в `main` в конце задачи — через 1–2 минуты сайт обновится.
Если чат стал очень длинным, напишите «Кончается контекст»: Claude сохранит и опубликует
рабочее состояние, а в новом чате вы напишете «Продолжи».

## Что делаете вы (задачи с 👤)
- **0.1** — переименовать репозиторий в `zhurnal`, сделать публичным, включить Pages
  (пошагово в карточке).
- **0.2** — создать бесплатный проект Firebase (пошагово в карточке) и прислать настройки.
- **0.3** — поговорить с мамой по вопросам из `docs/domain.md`, ответы — в чат.
- **1.4, 1.6, 1.9** — показать демо маме, уточнить правила курсов, проверить печать.
- **1.10** — установить на телефоны семьи, перенести текущие курсы из тетради, собрать замечания.
- **Перед этапом 3** — собрать 30–50 настоящих фраз, которыми мама записывает пациентов.

## Безопасность
- Пароли семьи храните у себя; в чат не присылайте.
- Настройки Firebase (`firebaseConfig`) и UID пользователей — не секрет, их можно присылать.
- В приложение не вносим фамилии, телефоны и диагнозы. Телефоны — только в памяти
  телефона (этап 2).

## Словарь
| Слово | Что значит |
|---|---|
| Репозиторий | папка проекта на GitHub: код, документация и история изменений |
| Коммит | сохранённый шаг изменений с подписью |
| Ветка | рабочая копия проекта, где идёт работа, не трогая опубликованную версию |
| `main` | главная ветка — то, что опубликовано на сайте |
| PR (pull request) | предложение влить изменения из ветки в `main`; видно, что поменялось |
| Merge (слияние) | принять PR; после этого сайт обновится |
| Revert (откат) | отменить слитые изменения, вернуть как было |
| PWA | сайт, который ставится иконкой и работает как приложение, даже без интернета |
| GitHub Pages | бесплатный хостинг сайта от GitHub |
| GitHub Actions | автоматика GitHub: прогоняет тесты и публикует сайт |
| Firebase, Firestore | бесплатная облачная база Google, где хранится журнал |
| Правила доступа | настройка базы: кто может читать и писать (только семья) |
| Кэш, сервис-воркер | копия сайта в телефоне — для работы без интернета и быстрого запуска |
| Демо-режим | приложение с выдуманными данными — для показа и тренировки |
| Тесты | автоматические проверки, что логика считает правильно |
| Смоук-проверка | быстрая автопроверка: приложение открывается без ошибок |
| Сессия | один чат с Claude, в котором выполняется одна задача |
| Карточка задачи | файл с описанием одной задачи: зачем, что сделать, как проверить |
