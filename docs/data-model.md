# Структура данных

Firestore — облачная база. Всего три вида документов.

## Соглашения
- Дата — строка `ГГГГ-ММ-ДД` («2026-09-25»). Время дня — минуты от полуночи
  (15:30 → 930). Часовых поясов нет: всё по времени устройства.
- ID — короткие случайные строки (8 символов `a-z0-9`).
- Кто изменил — ключ человека из справочника (`mama`, `papa`, `doch`, …).
- Персональных данных нет (`docs/project.md` → «Данные и закон»).
- Правка — точечно, по пути поля (`visits.<id>`), а не перезаписью документа:
  тогда двое, правящие разные визиты, не мешают друг другу.

## `meta/settings` — справочники
```js
{
  seedVersion: 1,
  workHours: { '1': [480, 1200], /* … */ '6': [540, 900], '0': null }, // день недели → [начало, конец]
  step: 5,                                     // шаг выбора времени, мин
  staff: {
    papa: { name: 'Папа', color: '#2f6fdf', order: 2 },
    // …
  },
  resources: {                                 // аппараты и места
    baro:  { name: 'Барокамера', capacity: 1, order: 1 },
    couch: { name: 'Кушетки (иглы)', capacity: 2, order: 7 },
    // …
  },
  procedures: {
    massage: {
      name: 'Массаж', short: 'Масс.',
      staff: 'papa',          // кто обычно делает (null — любой)
      resource: null,         // какой аппарат/место занимает
      hands: 'full',          // 'full' весь сеанс | 'setup' поставить и снять | 'start' только запуск | 'none'
      handsMin: 0,            // для 'setup' и 'start': сколько минут нужны руки
      duration: 40,           // обычная длительность, мин
      synonyms: ['массаж', 'масаж'],
      order: 1
    },
    // …
  }
}
```

## `meta/patients` — все пациенты в одном документе
```js
{
  list: {
    k3f9x2ab: {
      name: 'Витя К.',                   // как в тетради
      aliases: ['витя', 'виктор'],       // как ещё называют — для поиска и фраз
      usual: [                           // обычный набор, подставляется при записи
        { proc: 'needles', dur: 30 },
        { proc: 'baro', dur: 40 }
      ],
      note: 'после школы, не раньше 16', // без медицинских сведений
      course: null,                      // текущий курс (задача 1.7)
      lastVisit: '2026-09-24',
      archived: false,
      updatedBy: 'mama', updatedAt: /* время сервера */
    }
  }
}
```
Почему один документ: при открытии — одно чтение вместо сотен. До ~1500 пациентов
помещается с запасом (лимит документа — 1 МБ).

## `days/{ГГГГ-ММ-ДД}` — один документ на день
```js
{
  visits: {
    v7hq2m0c: {
      pids: ['k3f9x2ab'],                  // один или несколько пациентов (группа)
      items: [                             // процедуры по порядку, у каждой своё время
        { proc: 'needles', start: 900, dur: 30, staff: 'mama' },
        { proc: 'baro',    start: 930, dur: 40 }
      ],
      text: '',                            // «карандашом» или заметка к визиту
      status: 'plan',                      // 'plan' | 'cancelled'
      courseId: null,                      // курс (задача 1.7)
      createdBy: 'mama', updatedBy: 'papa', updatedAt: /* время сервера */
    }
  },
  blocks: {                                // личные блоки: человек занят
    b1x9k2m4: { staff: 'mama', start: 780, end: 840, text: 'за ребёнком' }
  },
  log: [                                   // история изменений за день (задача 1.8)
    { at: 1790000000000, by: 'papa', text: 'Витя К.: 15:00 → 17:00' }
  ]
}
```
- `items[].staff` — кто делает; нет поля — берётся из справочника процедуры.
- `items[].pids` — необязательно: кто из группы на этой процедуре. Для этапа 5,
  пока не используется.
- `log[].at` — время устройства в мс (серверное время внутри массивов Firestore
  не поддерживает).
- Отменённые визиты видны зачёркнутыми и не участвуют в наложениях.
- Перенос на другой день — одна пакетная запись: удалить в старом дне + записать в новом.

## Чтения и лимиты
Открыть приложение: settings (1) + patients (1) + текущий день (1) + соседние дни (2)
≈ 5 чтений. Неделя на шкале — 7 чтений. Бесплатно в день: 50 000 чтений и 20 000 записей —
запас в сотни раз.

## Правила доступа — `firebase/firestore.rules`
```
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    function isFamily() {
      return request.auth != null
        && request.auth.uid in ['UID_1', 'UID_2', 'UID_3', 'UID_4'];
    }
    match /{doc=**} {
      allow read, write: if isFamily();
    }
  }
}
```

## Копия
«Скачать копию» (задача 1.8) — файл JSON:
`{ exportedAt, settings, patients, days: { 'ГГГГ-ММ-ДД': {…} } }`. Из него можно
восстановить всё.

## Изменение структуры
Только вместе с миграцией (функция в `db-*.js`, которая приводит старые данные к новому виду)
и записью в `docs/decisions.md`.
