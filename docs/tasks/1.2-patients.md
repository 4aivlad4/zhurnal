# 1.2 Пациенты

Этап 1 · Размер M · Статус ⬜

## Зачем
Карточка пациента помнит его обычный набор процедур с его минутами — тогда запись
занимает пару нажатий.

## Прочитать
- `docs/data-model.md` — «meta/patients»
- `docs/domain.md` — «Процедуры», «Визит»
- `docs/code-rules.md` — раздел 4

## Сделать
1. Экран «Пациенты»: поиск по первым буквам — по имени и «как ещё называют»,
   без учёта регистра и ё/е; сверху — недавние; кнопка «+ Новый».
2. Карточка: имя как в тетради (подсказка «без фамилий, телефонов и диагнозов»),
   «как ещё называют», обычный набор процедур (добавить, убрать, порядок ↑↓, минуты ±5),
   заметка, «в архив».
3. `logic/patients.js` + тесты: поиск и нормализация (ё → е, регистр), сортировка.
4. Функция «новый пациент одним именем» — понадобится в записи (1.4).

## Не делать
- Телефоны (этап 2), курсы (1.7).

## Готово, когда
- [ ] завести «Витя К.» с набором «иглы 30, барокамера 40» — меньше минуты
- [ ] поиск «ви» и «виктор» находит его
- [ ] работает в демо и в настоящем режиме; тесты зелёные; скриншоты отправлены
