# 1.8 Печать, копия, история, отмена

Этап 1 · Размер M · Статус ⬜ · 👤

## Зачем
Доверие к журналу: день можно распечатать, данные — сохранить копией, видно, кто что
поменял, а ошибку можно отменить.

## Прочитать
- `docs/data-model.md` — «days/{ГГГГ-ММ-ДД}» (log), «Копия»
- `docs/architecture.md` — «Хранилище»

## Сделать
1. «Печать дня»: лист А4 крупным шрифтом, список по времени; по желанию — по людям.
   С моноблока — обычная печать браузера.
2. «Скачать копию» в «Ещё»: файл JSON со всем журналом. Совет в интерфейсе:
   «раз в неделю с моноблока».
3. История: каждое изменение → строка в `log` дня («Папа: Витя К. 15:00 → 17:00»);
   экран «История дня».
4. «Отменить» после любого действия: плашка на 5–10 секунд + последние 20 действий
   в пределах сессии.

## Не делать
- Восстановление из копии кнопкой — при необходимости вручную через Claude.

## Владелец 👤
Распечатать день на моноблоке и проверить, что читается.

## Готово, когда
- [ ] распечатанный день читается
- [ ] копия скачивается и содержит все дни
- [ ] история показывает, кто что поменял
- [ ] «Отменить» возвращает как было; логика отмены покрыта тестами
