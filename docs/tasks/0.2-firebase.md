## Владелец 👤 (≈20 минут, удобнее с компьютера)
1. console.firebase.google.com → войти Google-аккаунтом → **Создать проект**
   (имя, например, `zhurnal-centra`); Google Analytics — выключить.
   Консоль не открывается — написать Claude: решим (VPN один раз для настройки
   или запасной вариант).
2. **Build → Firestore Database → Create database**: редакция Standard (если спросит),
   расположение **europe-west3 (Frankfurt)** — потом не меняется, режим **production**.
3. **Build → Authentication → Get started → Email/Password** → включить.
   **Users → Add user** — по одному на человека: `mama@example.com`, `papa@example.com`,
   `doch@example.com` и свой (например, `admin@example.com` — на экране это кнопка «Другой»).
   Почты выдуманные, письма не приходят. Логины видны в коде сайта, поэтому пароли —
   от 8 символов и не простые; записать у себя, в чат не присылать.
   **Settings → User actions** → снять «Enable create (sign-up)» (если пункта нет — не страшно:
   защищают правила доступа).
4. ⚙ **Project settings → Ваши приложения →** значок `</>` → зарегистрировать веб-приложение →
   скопировать блок `firebaseConfig` и прислать в чат (это не секрет).
   Из **Authentication → Users** прислать колонку **User UID** с подписью, чей (тоже не секрет).
5. Когда Claude подготовит правила: **Firestore → Rules** → заменить текст содержимым
   `firebase/firestore.rules` → **Publish**.
6. Желательно: ограничить ключ адресом сайта — Google Cloud Console → Credentials →
   Browser key → HTTP referrers: `https://4aivlad4.github.io/*`.

   «Проверить» → «Связь есть: запись 0,4 с, чтение 0,2 с» или понятная ошибка.
5. `firebase/firestore.rules` с присланными UID.
