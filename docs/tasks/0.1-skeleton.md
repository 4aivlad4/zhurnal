# 0.1 Каркас и публикация

Этап 0 · Размер M · Статус ⬜ · 👤

## Зачем
Получить адрес сайта и иконку «Журнал» на телефоне, настроить автопубликацию —
дальше каждое изменение само доходит до телефонов.

## Прочитать
- `docs/architecture.md` — «Файлы», «Обновления на телефонах», «Публикация», «Проверки»
- `docs/code-rules.md` — целиком
- `docs/decisions.md` — Р-13, Р-14

## Сделать
1. `app/index.html`, `app/css/`, `app/js/main.js`: страница-заглушка «Журнал центра»
   с крупным заголовком и номером версии из `app/js/version.js`.
2. Preact + htm одним файлом в `app/vendor/`; `app/vendor/README.md` — версия и источник.
   Заглушку отрисовать через Preact — заодно проверка, что библиотека работает.
3. PWA: `manifest.webmanifest` (имя «Журнал», цвета, иконки 192 и 512 PNG + maskable),
   `sw.js` (кэш файлов сайта по версии; новая версия включается при следующем открытии).
4. `package.json` без зависимостей для сайта: `npm test` (`node --test tests/`),
   `npm run serve` (локальный сервер для `app/`), `npm run smoke` (Playwright: окно 390×844,
   ошибки в консоли = провал, скриншот). Playwright — только devDependency.
5. `tests/`: первый тест (например, формат версии) и смоук.
6. `.github/workflows/pages.yml`: push в `main` → `npm test` → публикация `app/`
   на GitHub Pages.
7. `.gitignore`: `node_modules`, скриншоты, временные файлы.
8. По возможности — хук старта сессии (скилл `session-start-hook`), чтобы зависимости
   для проверок ставились сами.

## Не делать
- Firebase, вход, экраны журнала.

## Владелец 👤
1. Если ещё не сделано: GitHub → репозиторий → **Settings** → General →
   Repository name: `zhurnal` → **Rename**; внизу страницы **Change visibility → Public**.
2. **Settings → Pages → Source: GitHub Actions**.
3. После публикации: на телефоне мамы открыть https://4aivlad4.github.io/zhurnal/ →
   меню Chrome ⋮ → **Установить приложение** (или «Добавить на главный экран»).

## Готово, когда
- [ ] сайт открывается по адресу на телефоне, видна версия
- [ ] иконка «Журнал» на главном экране открывает приложение без адресной строки
- [ ] в авиарежиме приложение всё равно открывается
- [ ] новая версия доходит до телефона со второго открытия
- [ ] `npm test` и `npm run smoke` зелёные
