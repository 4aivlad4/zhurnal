# 1.3 Экран «День»

Этап 1 · Размер M · Статус ⬜

## Зачем
Главный экран — день списком, как в тетради, но на любом телефоне и сразу у всех.

## Прочитать
- `docs/data-model.md` — «days/{ГГГГ-ММ-ДД}»
- `docs/domain.md` — «Визит»
- `docs/code-rules.md` — раздел 4

## Сделать
1. Шапка: ← дата → (с днём недели словами), «Сегодня», выбор даты календариком.
2. Список визитов по времени: «15:00–16:55 · Витя К. · иглы → барокамера → ЛФК».
   Группа — несколько имён; «карандашом» — текстом; отменённые — зачёркнуты;
   личные блоки — серой строкой «Мама занята 13:00–14:00 · за ребёнком».
3. Фильтр по человеку «Все / Мама / Папа / Дочь» — «мой день».
4. Счётчик визитов за день; пустой день — «Записей нет. Нажмите +».
5. Большая кнопка «+» и нажатие на визит — пока заглушки (запись и правка — 1.4).
6. `logic/visits.js` + тесты: начало и конец визита, сортировка, текст цепочки.
7. Изменения с других устройств появляются сами.

## Не делать
- Запись и правку (1.4), предупреждения (1.5), отметку явки (1.6).

## Готово, когда
- [ ] день из 30–40 визитов (демо) читается на телефоне без увеличения
- [ ] дни листаются мгновенно, «Сегодня» возвращает к текущему
- [ ] фильтр «Папа» оставляет только визиты с его процедурами
- [ ] тесты и смоук зелёные; скриншоты отправлены
