# 1.10 Запуск

Этап 1 · Размер S · Статус ⬜ · 👤

## Зачем
Перейти с тетради на приложение без стресса: 2–4 недели параллельно, с памяткой
и сбором замечаний.

## Прочитать
- `docs/project.md` — «Принципы», «Риски»
- `docs/owner-guide.md` — «Как проверить результат»

## Сделать (Claude)
1. Памятка для семьи `docs/family-guide.md` и версия для печати (1 страница А4, крупно):
   как записать, перенести, отменить; что делать без интернета; к кому идти, если что-то не так.
2. Очистить настоящую базу от тестовых данных; демо остаётся отдельным режимом.
3. Чек-лист установки на телефон — для владельца.

## Владелец 👤
1. Установить приложение на телефоны мамы, папы, дочери и на моноблок; войти за каждого.
2. Показать маме: записать, перенести, отменить, отметить явку (10 минут).
3. Перенести текущие курсы из тетради: у каждого пациента — сколько куплено
   и сколько уже было. Можно постепенно, по мере прихода пациентов.
4. 2–4 недели — параллельно с тетрадью. Замечания собирать как есть (в чат, можно голосом).
5. Раз в неделю присылать замечания — Claude разложит их по плану.

## Готово, когда
- [ ] приложение установлено у всех, вход выполнен
- [ ] неделя записей в приложении без потерь; счётчики курсов сходятся с тетрадью
- [ ] замечания разобраны: «сразу» / «в этап 2» / «не делаем»
