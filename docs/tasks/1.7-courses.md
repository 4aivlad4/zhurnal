# 1.7 Курсы и повторы

Этап 1 · Размер M · Статус ⬜

## Зачем
Не переписывать одно и то же: курс «пн-ср-пт ×10» создаётся одной командой,
неделя — копией.

## Прочитать
- `docs/data-model.md` — «days/{ГГГГ-ММ-ДД}», «meta/patients» (course)
- `docs/domain.md` — «Визит»
- `docs/code-rules.md` — разделы 2, 3

## Сделать
1. В правке визита — «Повторить…»: дни недели, «N раз» или «до даты», пропуск нерабочих дней.
   Перед созданием — список дат с отметками наложений; отдельные даты можно снять.
2. Курс: счётчик «3 из 10» у визитов курса и в карточке пациента.
3. «Скопировать неделю»: из выбранной недели в другую — с предпросмотром и наложениями;
   отменённые не копируются.
4. `logic/courses.js` + тесты: даты по дням недели, нерабочие дни, наложения в предпросмотре.

## Готово, когда
- [ ] курс из 10 визитов создан одной командой, видно «n из 10»
- [ ] копия недели с предпросмотром работает
- [ ] тесты и смоук зелёные
