# 1.5 Наложения и личные блоки

Этап 1 · Размер M · Статус ⬜

## Зачем
Приложение само замечает «папа нужен в двух местах» или «барокамера занята»
и предупреждает, но решает человек.

## Прочитать
- `docs/domain.md` — «Процедуры», «Правила наложений»
- `docs/data-model.md` — «days/{ГГГГ-ММ-ДД}» (items, blocks)
- `docs/code-rules.md` — разделы 2, 3

## Сделать
1. `logic/conflicts.js`: «день + справочники → список предупреждений» по правилам
   из `docs/domain.md`: аппарат, руки специалиста («весь сеанс», «поставить и снять»,
   «только запуск»), пациент в двух местах, личный блок, вне часов работы.
   Отменённые визиты не учитываются.
2. Тесты: каждое правило; граница (конец одной = начало другой — не наложение);
   иглы (руки только в начале и в конце); группа; день из 40 визитов.
3. «День»: ⚠ у визитов с наложением; по нажатию — понятный текст:
   «Папа в 15:30–16:10 уже с Петей (массаж)».
4. Запись и правка: предупреждение до сохранения — «Всё равно сохранить» / «Изменить время».
5. Личные блоки: «+ Занят» → человек, время, причина; видны в «Дне», учитываются в наложениях.

## Готово, когда
- [ ] все правила покрыты тестами, тесты зелёные
- [ ] в демо наложение массажа видно красным, сохранить всё равно можно
- [ ] блок «мама 13–14» виден всем и даёт предупреждение
- [ ] скриншоты отправлены
