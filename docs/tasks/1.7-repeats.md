# 1.7 Повторы и копия недели

Этап 1 · Размер M · Статус ⬜

## Зачем
Не переписывать одно и то же: визиты на весь курс («пн-ср-пт ×10») создаются
одной командой, неделя — копией.

## Прочитать
- `docs/data-model.md` — «days/{ГГГГ-ММ-ДД}» (series), «meta/patients» (course)
- `docs/domain.md` — «Визит», «Курсы и явка»
- `docs/code-rules.md` — разделы 2, 3

## Сделать
1. В правке визита — «Повторить…»: дни недели, «N раз» или «до даты», пропуск нерабочих дней.
   N по умолчанию — сколько осталось по курсу пациента.
   Перед созданием — список дат с отметками наложений; отдельные даты можно снять.
2. Созданные визиты — одна серия: «Отменить все следующие визиты серии» (с подтверждением).
3. «Скопировать неделю»: из выбранной недели в другую — с предпросмотром и наложениями;
   отменённые не копируются.
4. `logic/repeats.js` + тесты: даты по дням недели, нерабочие дни, «до даты»,
   наложения в предпросмотре.

## Не делать
- Счётчик посещений и явку — это 1.6.

- [ ] «отменить все следующие» работает
- [ ] копия недели с предпросмотром работает
- [ ] тесты и смоук зелёные
