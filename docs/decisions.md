## Принятые решения

- **Р-1. PWA-сайт**, не приложение из магазина: ставится иконкой, работает без интернета,
  обновляется само, бесплатно.
- **Р-2. Без сборки**: JS-модули + Preact/htm из `app/vendor/`. Меньше инструментов —
  меньше поломок; что в репозитории, то и работает.
- **Р-3. Хранилище — Firebase** (Firestore + Auth, бесплатный тариф Spark): синхронизация
  за секунды, офлайн из коробки, своего сервера нет. Риск — доступность из РФ: проверяем
  в 0.2; работа с базой изолирована в `db-firebase.js`; запасной план — в `docs/architecture.md`.
- **Р-4. Один документ на день**, один на пациентов, один на справочники: мало чтений
  (лимиты), наложения считаются по одному документу, правки точечные.
- **Р-5. Минимум данных**: в облаке — как в тетради (имя с пометкой, время, процедуры).
  Без фамилий, телефонов, диагнозов.
- **Р-6. Ввод**: основа — пошаговая запись; быстрая строка — этап 3; голос — микрофон
  клавиатуры; ИИ — этап 5, по желанию; локальную нейросеть не делаем.
- **Р-7. Наложения — предупреждения**, не запреты; приложение ничего не отменяет само.
- **Р-8. Каждому свой вход** (мама, папа, дочь, владелец) — видно, кто что поменял.
- **Р-9. Время** — минуты от полуночи, даты — `ГГГГ-ММ-ДД`, без часовых поясов.
- **Р-10. Справочники** меняются через Claude (seed + номер версии); экран
  редактирования — позже, если понадобится.
- **Р-11. Процесс**: одна задача — одна сессия; карточки задач; короткие отчёты;
  подробности — только где нужна реакция владельца. Сессия заканчивается PR
  с рабочим состоянием.
- **Р-12. В документации нет реальных имён** сотрудников и пациентов — репозиторий публичный.
- **Р-13. Публикация — GitHub Pages.** Репозиторий публичный и называется `zhurnal`;
  адрес сайта — https://4aivlad4.github.io/zhurnal/. Данных пациентов и паролей
  в репозитории нет.
- **Р-14. Слияние в `main` — Claude сам** (сжатием, squash): в конце задачи или когда
  владелец пишет «кончается контекст». Одна задача — один коммит в `main`, откат — revert.
- **Р-15. Явка и счётчик посещений** (добавлено владельцем в этап 1, задача 1.6).
  Курс — N купленных посещений. Явка отмечается у каждого пациента визита:
  «пришёл» / «не пришёл». Закончившиеся визиты без отметки приложение предлагает отметить
  («Итог дня»). Счётчик хранится в карточке пациента; источник правды — отметки в днях.
  Денег нет — только посещения.
- **Р-16. Preact + htm — один готовый файл** `app/vendor/preact-htm.js`: `preact/standalone`
  из npm-пакета htm 3.1.1 (внутри Preact 10 и хуки), без изменений. Источник и SHA-256 —
  в `app/vendor/README.md`.
- **Р-17. Работа без интернета и обновления.** Сервис-воркер модульный и берёт версию
  из `js/version.js`: поднять версию — и телефоны обновятся. Сохраняемые файлы перечислены
  в `js/offline-files.js`; тест сверяет список с папкой `app/`. Новая версия скачивается
  в фоне при открытии и сразу включается — видна со второго открытия. Браузер без модульных
  сервис-воркеров откроет журнал только с интернетом.
- **Р-18. Проверки на GitHub**: тесты — на каждый PR и перед публикацией; публикуется
  только `main`. Смоук (Playwright) запускает Claude в сессии; зависимости для него ставит
  хук старта `.claude/hooks/session-start.sh`.
- **Р-19. Значок** — белая «Ж» на синем (`#1f5f8b`). Исходник — `app/icons/icon.svg`;
  PNG 192, 512 и маскируемая (для круглых значков Android) сделаны из него.
- **Р-20. Firebase — три файла** в `app/vendor/firebase/`: `firebase-app.js`, `firebase-auth.js`,
  `firebase-firestore.js` версии 12.19.0 из npm-пакета `firebase` (совпадают с файлами на сервере
  Firebase). Единственная правка — `firebase-app.js` подключается как соседний файл, а не с сервера
  Google. Тест `tests/vendor.test.js` следит, чтобы код сайта ничего не подключал из интернета.
- **Р-21. Вход и проверка связи.** Только логин и пароль, без окон «Войти через Google»
  (`initializeAuth` без них): меньше файлов с серверов Google. Вход помнится на устройстве.
  Логины — `mama`, `papa`, `doch` + `@example.com`; «Другой» — ввести логин, короткий дополняется
  `@example.com`. Проверка пишет служебный документ `meta/ping` (`{ by, at }`): запись засчитана,
  когда её подтвердил сервер; чтение — с сервера, а не из копии в устройстве. Ответа нет 15 секунд —
  «Сервер не ответил».
